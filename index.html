CASE STUDY SPECIFICATIONS

RFID-Based Smart Self-Checkout System

Complete Hardware & Software System Architecture

A final-year Computer Engineering project designed to automate the retail checkout process by combining RFID, computer vision, weight verification, embedded systems, REST APIs, digital payment, and automated anti-theft security.

Product Identification & Checkout ESP32-based checkout hardware with an RC522 RFID reader/writer for product identification and RFID-based checkout operations.
Weight Verification Load cell and HX711 amplifier used to measure and verify product weight during the checkout process.
AI-Based Product Identification ESP32-CAM running an Edge Impulse machine-learning model to identify products using computer vision.
Backend & System Integration Django REST API connecting the embedded hardware with the web-based system, handling product data, cart information, inventory, checkout processing, and system communication.
Digital Payment Chapa payment gateway integrated for customer payment processing and payment-status verification through webhooks.
Anti-Theft Exit Security An automated servo-controlled exit gate with LED and buzzer indicators verifies the customer's checkout status and controls whether the gate is allowed to open.
